# Public Static Assets Directory

You can place your image files in this `public` directory using the **File Explorer** in the left sidebar.

The application components are configured to automatically display images from this directory:

- `/public/founder.jpg` — Used in the **Founder & Principal Dentist** section.
- `/public/clinic.jpg` — Used in the **Main Clinic Storefront / Building** section.
- `/public/logo.png` — Used in the **Header & Medallion Brand** components.

### How to Upload Your Files:
1. Open the **File Explorer** on the left.
2. Select or right-click the `public` folder.
3. Click **Upload File** (or drag & drop your image file into `public`).
4. Rename your uploaded files to `founder.jpg`, `clinic.jpg`, or `logo.png`.

The app will instantly render your uploaded image files with zero code changes required!
